# Roadmap · Lumina

Lo que sea para después tiene que estar en una hoja de ruta. No puede ser que no tengamos un roadmap.

Fuente de verdad: `ROADMAP.md` en la raíz. El canvas `lumina-roadmap.canvas.tsx` resume; no lo contradigas.

## Cuando algo no se hace ahora

1. Abrí `ROADMAP.md`.
2. Si la fila no existe, agregala.
3. Campos obligatorios: **frente · ítem · dueño · ventana · hecho-cuando · estado**.
4. Dueño es una persona o rol real: código, org (CUIT/banco), contador, app. No “Lumina” genérico.
5. En el chat, nombrá la fila. No digas “después” suelto.

## Estados

- `ahora` — se está haciendo o es el recorte hackathon
- `siguiente` — bloquea operar con plata o factura
- `fecha` — ventana en el archivo (no “algún día”)
- `hecho` — hay evidencia (CUIT, CAE, tx, deploy)

## No

- Mover un hueco a “visión” para no decidirlo.
- Duplicar el mismo ítem en tres fases.
- Marcar hecho un cobro simulado.
